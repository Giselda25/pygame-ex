# Простая анимация ходьбы на Pygame

Учебный проект на Python с использованием библиотеки "pygame". Реализует управление персонажем и покадровую анимацию движения.

## Особенности проекта
- **Покадровая анимация:** Анимация ходьбы собрана из 10 последовательных PNG файлов (`walk_1.png`, ... `walk_10.png`), полученных из исходного GIF-файла.
- **Управление:** Перемещение персонажа по экрану с помощью клавиатуры, стрелок или WASD.
- **Оптимизация:** Плавное переключение кадров, до 60 фпс.

## Требования
- Python 3
- Библиотека "pygame"
