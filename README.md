# Мини игра с зомби на Pygame

Учебный проект на Python с использованием библиотеки "pygame". Реализует управление персонажем, покадровую анимацию движения и стрельбы. Добавлены случайно появляющиеся объекты в виде зомби.

## Особенности проекта
- **Покадровая анимация:** Анимация ходьбы собрана из 10 последовательных PNG файлов (`walk_1.png`, ... `walk_10.png`), полученных из исходного GIF-файла.
- **Управление:** Перемещение персонажа по вправо/влево с помощью клавиатуры, стрелок или WASD.
- **Оптимизация:** Плавное переключение кадров, до 60 фпс.
- **Стрельба** Анимация стрельбы сделана из уникального PNG спрайта, при выстреле появляется пуля, при попадании в объект(зомби), он умирает(пока что просто исчезает). Стрелять на пробел.
- **Зомби** Добавлены случайно появляющиеся объекты справа и слева, объекты имеют вид зомби и покадровую анимацию ходьбы.

## Требования
- Python 3
- Библиотека "pygame"
