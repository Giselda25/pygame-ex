# Мини игра с зомби на Pygame 🧟

Учебный проект на Python с использованием библиотеки "pygame". Реализует управление персонажем, покадровую анимацию движения и стрельбы. Добавлены случайно появляющиеся объекты в виде зомби.

## Особенности проекта
- **Покадровая анимация:** Анимация ходьбы собрана из 10 последовательных PNG файлов (`walk_1.png`, ... `walk_10.png`), полученных из исходного GIF-файла.
- **Управление:** Перемещение персонажа вправо/влево с помощью клавиатуры, стрелок или WASD.
- **Оптимизация:** Плавное переключение кадров, до 60 фпс.
- ## 🧟 Обновления и новые функции №1
- **Стрельба:** Анимация стрельбы сделана из уникального PNG спрайта, при выстреле появляется пуля, при попадании в объект(зомби), он умирает(пока что просто исчезает). Стрелять на пробел.
- **Зомби:** Добавлены случайно появляющиеся объекты справа и слева, объекты имеют вид зомби и покадровую анимацию ходьбы.
- ## 🛠️ Обновления и новые функции №2
- **Камера с прокруткой:** Игровой мир расширен до 1600 пикселей, камера следует за перемещением персонажа.
 **Пиксельный интерьер:** Добавлен задник комнаты в ретро-стиле.
- **Интерактивные объекты(взаимодействие клавишей E):**
- **Тумбочка:** при взаимодействии работает как аптечка.
- **Радио:** включает и выключает фоновую музыку.
- **Боевая система и здоровье:**
  * У игрока появилось здоровье с визуальной полоской HP над персонажем.
  * Реализован экран «ИГРА ОКОНЧЕНА» при смерти игрока, с возможностью рестарта по нажатию клавиши `Enter`.
  * У зомби появилась шкала здоровья и шанс хедшота с мгновенным убийством.
- **Система патронов:** Добавлен счетчик патрон, с расходом при стрельбе и перезарядкой по клавише `R`.
- **Звуковые эффекты:** Добавлен звук выстрела (`shot.mp3`), попаданий по зомби (`hit.mp3`) и перезарядки (`reload.mp3`).
